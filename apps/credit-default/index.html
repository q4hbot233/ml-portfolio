Credit risk · fairness

Who pays for the model's mistakes?

In shortA default model for 30,000 credit card clients (Taiwan, 2005), carried past the ROC curve to the lending decision. If a missed default costs ten times a false alarm, the cheapest cutoff is about 0.09, and the usual 0.5 costs about 2.1 times as much. That ratio is an assumption, so the page lets you change it and shows which groups of clients absorb the errors. It also changes which of the two models should be deployed.

Starting Python in your browser. Up to a minute the first time; cached after that. Nothing is sent to a server.
