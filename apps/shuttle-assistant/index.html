A shuttle assistant that refuses

A passenger intent router for a driverless shuttle, and the trade-off it is actually judged on: refusing the questions no handler owns.

Starting a Python runtime in your browser — this takes about 10–20 seconds on a first visit, then it is cached. The classifier is then fitted here, on this page, from the shipped training split; nothing is sent to a server and no model file is downloaded.
